# Cloud number (Telnyx)

Catalog-only third-party service — not a REΛVE plugin. Invoice and bookkeeping only.

Telnyx markets this as **Global Numbers** / **Phone Numbers**: local, national, toll-free, and vanity. Public label here is **Cloud number** so it does not sound like a cable-company desk line.

Telnyx bills the number monthly (from about $1). Do not enable in install `features[]`. Must not appear on deploy, the demo builder, or the public add-ons page.

## External setup

- Search and buy a local, toll-free, or vanity DID in Telnyx
- Voice + SMS on the same number when needed
- Forwarding / voicemail as agreed
- Invoice REΛVE setup separately from Telnyx’s monthly number fee

# Social inbox

Unified activity for the networks this install chose — comments, mentions,
posts, plus Google / Yelp reviews when Reviews is also on.

This is a **paid add-on**. Clients purchase it from admin → Modules. They
cannot enable it themselves.

## What ships

- Email-style inbox: network tabs on the list, reply / open on the right
- New post: write once, copy, open each network (in-app publish is not live)
- Replies: draft in Reave (or tap Write with agent), then open the network
- New email and social compose use the same Write with agent control
- Inbox tabs include every network kept visible under Socials (YouTube, TikTok, and the rest) plus Google / Yelp when Reviews is on

## Legal / API notes

Use official platform APIs and business accounts only. Do not scrape. Google
Places and Yelp have display and caching rules; owner replies usually need
the Business Profile / partner APIs, not Places. Counsel should review before
a public sale.
